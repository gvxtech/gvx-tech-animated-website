GVX TECH - Futuristic Single Page Website

FILES
- index.html: complete single-page website
- style.css: responsive dark/cyan styling and animations
- script.js: navigation, scroll reveals, gentle pointer movement and enquiry email
- assets/images/gvx-robot-earth.webp: robot + digital Earth artwork taken from the supplied GVX TECH reference image

IMPORTANT ARTWORK NOTE
The supplied robot and Earth artwork is retained as an image. It is not recreated, replaced, or converted into a different 3D model. The movement is applied around the artwork (glow, orbital lines, particles and subtle floating/parallax effects).

RUN
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open index.html with Live Server, or upload the folder contents to your hosting.

The site uses Google Fonts from the internet. No Three.js/WebGL dependency is required.

CONTACT FORM
The enquiry form opens the visitor's email app. Before publishing, replace hello@gvxtech.com in script.js with the official GVX TECH email address. For server-side form submission, connect the form to a backend or form service.
